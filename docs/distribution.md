The first local stage only establishes the package: it must not be approved as the release because it lacks GitHub provenance.

Configure an npm trusted publisher restricted to `ViceScale/n8n-nodes-airscale`, workflow `publish.yml`, with staging permission only. No reusable npm publishing token is needed. Create a version tag matching package.json, then manually dispatch Publish on that tag. It validates, tests and calls `npm stage publish --provenance --access public`. `RELEASE_MODE=true` permits the official n8n-node prerelease lifecycle; lint/build are still enforced. No branch push automatically stages or publishes. Inspect the GitHub-built stage's version, provenance and tarball hash before approving it with npm 2FA. Reject the earlier local bootstrap stage, then verify the public registry metadata and installation. The workflow uses npm 11.21.3 because staged publishing requires npm 11.15 or newer.

After npm publication, submit the package through https://creators.n8n.io/nodes. Provide a reviewer account/test budget only with owner authorization. Do not claim paid modules have been live-tested when only fixtures were used. Complete reviewer-required fields using confirmed company details and actual evidence. Acceptance and Cloud discovery are external n8n decisions.

Official requirements: https://docs.n8n.io/connect/create-nodes/build-your-node/reference/verification-guidelines and https://docs.n8n.io/connect/create-nodes/deploy-your-node/submit-community-nodes.
